# Architecture decision records

ADRs explain a significant choice, its context, alternatives and consequences.
They complement the [architecture walkthrough](../architecture.md), which explains
the system as a whole.

- [0001 PostgreSQL with SQLAlchemy and Alembic](0001-database-choice.md)

For a new decision, add the next numbered Markdown file with: title, status, context,
decision, alternatives, consequences and implementation references. Mark superseded
records and link their replacements rather than rewriting history. The first record
retrospectively documents the implemented database choice; it is not evidence of an
original approval meeting.
